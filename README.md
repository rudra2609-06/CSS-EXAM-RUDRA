# Exam Landing Page

This is a responsive and modern landing page designed using **HTML** and **CSS**. It features a sleek navigation bar, dropdown menu, and a hero image, suitable for educational platforms or portfolio use.

---

## 🚀 Project Overview

This project represents a clean and functional front-end design for an educational or tech-focused website. Key components include:

- Responsive navigation header with dropdowns
- Hero section with featured image
- Google Fonts and Bootstrap Icons integration
- Reusable utility classes using Flexbox

---

## 🎨 Technologies Used

- **HTML5** for structure  
- **CSS3** for styling and layout  
- **Google Fonts**: [Roboto](https://fonts.google.com/specimen/Roboto), [Manrope](https://fonts.google.com/specimen/Manrope)  
- **Bootstrap Icons CDN** for dropdown arrow

---

## 💡 Features

- Responsive and modern design
- Dropdown menu using only CSS (no JavaScript)
- Clean typography with Google Fonts
- Utility classes for layout (Flex
